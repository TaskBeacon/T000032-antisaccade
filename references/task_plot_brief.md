# Task Plot Brief

## Task

- Title: Antisaccade Task
- Construct: inhibitory control / response inhibition / oculomotor control
- Paradigm: rule-dependent same-side or opposite-side response to a lateral target.

## Rows

- Prosaccade: respond toward the target side.
- Antisaccade: respond opposite the target side.
- Timeout: no left/right response before deadline.

## Trial Timeline

1. Fixation: 800-1200 ms. Show fixation and peripheral anchors, no response.
2. Rule cue: 400-600 ms. Show pro or anti rule cue, no response.
3. Gap: 150-250 ms. Keep neutral anchors, no response.
4. Saccade response: 1000 ms. Show left or right target. Press F for left, J for right.
5. ITI: 600 ms neutral fixation scene, no response.

## Notes

- Prosaccade correct response is same side as target.
- Antisaccade correct response is opposite side from target.
- Keyboard direction keys are used as a portable proxy for gaze direction.
